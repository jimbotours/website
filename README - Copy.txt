JIMBOTOURS WEBSITE V3
======================

This folder is Jimbotours Website V2, a self-contained static website built from your rescued GetJealous archive.

OPEN LOCALLY
Double-click:
index.html

IMPORTANT
The website contains copied local versions of the rescued photographs, so it does not depend on GetJealous or your old archive folder paths.

CONTENTS
- index.html        homepage
- trips.html        clickable trip index
- trips\            individual trip pages
- timeline.html     all diary entries
- map.html          interactive trip map
- about.html        archive background
- entries\          individual diary pages
- assets\photos\    copied rescued photographs
- assets\css\       website styling

BACKUP
Copy the entire Jimbotours_Website_V7_4_COLOUR_ROUTES folder to an external drive or another cloud location.

PUBLISHING
Because this is a static website, it can later be published to many web hosts without a database or WordPress.
